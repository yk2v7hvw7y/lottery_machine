# 抽奖名单批量导入说明

## 操作步骤

1. 在主文件夹内新建一个**子文件夹**（名称任意），用于存放本次要导入的内容。
2. 在该子文件夹中新建一个 **txt 文档**，并命名为 `抽奖范围.txt`。
3. 在 `抽奖范围.txt` 中按下述**格式**填写每一条抽奖内容。
4. 若某条目配有图片，把图片一并放入同一个子文件夹（图片文件名需与文档中的写法保持一致）。

## 内容格式

每条记录由 `任务`、`说明`、`图像` 三个字段组成，示例：

```text
任务 XXX
说明 XXX
图像 XXX.jpg

任务 AAA
说明 AAA
图像无
```

## 注意事项

1. **条目之间空一行**，便于程序识别每条记录的边界。
2. `任务`、`说明`、`图像` 这三个字段名**不可修改**，且字段名与内容之间需**空一格**。
3. **`说明` 和 `图像` 二选一填写**：填写了 `说明` 就不填 `图像`，反之亦然；没有对应内容时直接写 `无`。
4. 图像仅支持 **jpg** 格式（建议使用小写后缀），文件名**支持中文**，直接放入子文件夹即可（记得与文档中引用的名称保持一致）。
